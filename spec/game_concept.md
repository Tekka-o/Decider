# 契約書査定ゲーム 仕様書 - 全体コンセプト (game_concept.md)

本ドキュメントは、「現代の架空の会社で働く中間管理職」となり、3人の部下が持ってくる契約書を毎日査定し続けるシミュレーションゲームの全体コンセプトを定義します。

---

## 1. ゲーム概要

* **タイトル**: 未定（契約書査定シミュレーション）
* **ジャンル**: 契約査定アドベンチャー / デスクワーク・サバイバル
* **ターゲット層**: 
  * 細かい文章の矛盾やビジネス文書としての不備をチェックするのが好きなプレイヤー
  * ルール（マニュアルやカレンダー）を照らし合わせて不備を見抜く、脳トレや書類審査系ゲームが好きなプレイヤー
* **プラットフォーム想定**: PC / Webブラウザ / モバイル
* **コア体験**:
  * 部下たちが持ち込む、怪しげな取引や致命的な誤字・不備を孕んだ契約書を見抜くスリルと快感。
  * 承認（緑）と破棄（赤）のハンコを押し分ける直感的なデスクワークアクション。
  * 中間管理職としての評価（信頼度）を保ちながら、1日でも長く会社で生き残るサバイバル感。

---

## 2. 世界観とストーリー

### 2.1. キャラクターと設定
プレイヤーは、現代の架空の会社に勤める**「中間管理職（課長など）」**です。
毎日、あなたの下で働く「3人の部下」が社外から仕事（案件）として契約書を持ってきます。
彼らは個性も能力もバラバラで、中にはミスが異常に多かったり、怪しい契約を平然と持ってくる部下もいます。
会社の利益を守る最後の砦として、あなたはデスクに座り、毎日契約書を査定し続けなければなりません。
ゲーム内カレンダーは**「4月10日」**から始まり、1日が経過するごとにカレンダーも1日ずつ進んでいきます。

### 2.2. ゲームオーバー
見落とし（承認すべきでないものを承認する、または承認すべきものを破棄する）による信頼度の低下は、**「1日の業務が終了したタイミング」**でまとめて計算され、その日の減少量（または回復量）と共に表示されます。
信頼度が **0以下** になると、プレイヤーは即座に**会社をクビ（解雇）**にされ、路頭に迷うゲームオーバー（エンディング）を迎えます。
本ゲームに「クリア」はなく、プレイヤーはクビになるまでに「何日間生き延びられるか（働けるか）」を競うエンドレス形式です。

## 3. 基本ゲームループ

```
[1日の開始 (Day X - カレンダーは4月10日より順次進行)]
  │
  ▼
[マニュアル・ガジェットの確認] (本日の正しい日付や取引条件の再確認)
  │
  ▼
[部下が契約書を持って登場] (画面左から書類が流れてきて、中央で停止。部下の「セリフ」が表示される)
  │
  ▼
[契約書の査定] (文面スクロール、裏面の確認、マニュアルや時計との照合)
  │
  ▼
[ハンコによる意思決定] (右にある「承認（緑）」か「破棄（赤）」の横長長方形スタンプをクリック。書類右下に押印)
  │  ※提出前なら別のハンコを押し直して上書き可能！
  ▼
[書類の提出] (上にスライドして提出 ※上にスライドする動きのみで提出を行う)
  │
  ▼
[1日の目標枚数を処理完了までループ]
  │
  ▼
[1日の終了・査定結果判定]
  ├─ 査定ミスがある場合、重要度に応じて信頼度が低下。
  ├─ 査定ミスがなく、ノーミス日数が「7日」に達した場合、信頼度が10回復（上限100）。
  │  │   ※7日間のノーミスカウントは「ミスをした翌日」または「回復した翌日」から再スタートします。
  │  ▼
  ├─ 信頼度変動（減少・回復値）と現在の信頼度を画面に表示。
  │  │
  │  ▼
  │ [信頼度が0以下？]
  │   ├─ (Yes) ─► [ゲームオーバー (解雇リザルト表示: 働いた日数、正解数、不正解数)]
  │   └─ (No) ──► [次の日 (Day X+1) へ] (目標処理枚数が1枚増加、最大10枚。カレンダーが1日進む)
```
